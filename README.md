# Nexus Corp - Human Resources Portal API

## Contexto de la Organización
Nexus Corp es una corporación que ha desarrollado una aplicación web interna para consultar perfiles, expedientes laborales y solicitudes de vacaciones de sus empleados. Antes de implementar mejoras mayores en su infraestructura, la dirección de TI ha solicitado una auditoría preliminar de seguridad para identificar malas prácticas y posibles vulnerabilidades en el código fuente.

## Objetivo de la Fase 1
Los alumnos deben realizar un análisis preliminar y un plan de auditoría **sin ejecutar herramientas de escaneo en esta etapa**, revisando la estructura del proyecto y los archivos clave para identificar los riesgos esperados.
